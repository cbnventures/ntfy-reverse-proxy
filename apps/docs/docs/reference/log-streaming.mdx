Stream real-time logs from your deployed <Terminology title="Cloudflare-hosted entry point that runs the pipeline" to="/docs/reference/terminology#worker">worker</Terminology> for debugging and monitoring using `npm run tail`.

## Starting the Log Stream

```bash
npm run tail
```

This requires `CLOUDFLARE_API_TOKEN` to be set in your `.env` file. The stream outputs color-formatted log entries to the terminal and writes raw JSON lines to `tail-logs.jsonl` for later analysis.

## Session Management

Log streaming sessions have a limited lifespan set by Cloudflare. The script handles this automatically:

- Fetches the actual session expiry time from the Cloudflare API.
- Restarts the session with a 5-minute buffer before expiry.
- Cleans up stale sessions on startup.
- Shuts down gracefully on Ctrl+C.

## Output Format

Log entries are color-coded by event type and status:

- **HTTP events** — Method, status code, URL, user agent, geolocation (country, ASN, IP), and per-<Terminology title="an ntfy instance defined by name, URL, and token" to="/docs/reference/terminology#server">server</Terminology> delivery results.
- **Email events** — From/to/subject and <Terminology title="module that transforms a payload into a notification" to="/docs/reference/terminology#interpreter">interpreter</Terminology> results.

## Config Resolution

The script discovers `config.json` from the current directory, project root, or XDG config directory. It uses the `worker_name` from your config to identify the correct <Terminology title="Cloudflare-hosted entry point that runs the pipeline" to="/docs/reference/terminology#worker">Worker</Terminology> on Cloudflare.
